# Hook, Script, Performance, And Visual Workflow

Use this method for a Level One 15–30 second reel. Keep the work short enough to help production rather than becoming its own project.

## Turn The Topic Into One Job

Write:

> Help [specific viewer] notice or understand [one problem, desire, mistake, or opportunity] so they [one belief or action].

If the sentence contains several outcomes, choose the one most useful to the viewer and most connected to the desired action.

### Reusable AI Prompt

> Turn this approved topic into one job for a 15–30 second reel. Identify the specific viewer, the immediate tension, the one useful belief or action, and the logical next step. Do not write the script yet. Do not add a second lesson. Put worthwhile extra ideas in a future-video list.

## Generate Hooks That Are Actually Different

Ask for hook approaches such as:

- direct problem;
- painful consequence;
- surprising contrast;
- useful curiosity gap;
- challenge or disagreement;
- honest confession;
- demonstration or visual proof;
- identity statement aimed at the viewer.

Do not ask for twenty vague variations. Generate eight to twelve distinct approaches, then keep the best three.

### Reusable AI Prompt

> Create ten distinctly different spoken or visual hooks for this one-video job. Use a mix of direct problem, consequence, contrast, curiosity, challenge, confession, demonstration, and viewer-identity approaches where they fit. Keep each hook short enough for the opening seconds. Do not use empty questions, fake urgency, unsupported claims, or clickbait the script cannot repay. For each hook, suggest one opening visual.

### Hook Score

Score each finalist from 1–5 for:

- relevance to the exact viewer;
- stopping power;
- immediate clarity;
- credibility;
- visual potential; and
- strength of the eventual payoff.

Reject a hook that scores well only because it is shocking. The video must repay the attention.

## Write The Script

Use this structure as guidance, not a rigid formula:

- **Opening:** hook or visual interruption;
- **Middle:** one useful explanation, contrast, proof point, example, or action;
- **Ending:** one natural next step.

A typical 20–30 second script often lands around 45–75 spoken words, but the timed human delivery is the real test. Emotional pauses and character reactions take time.

### Reusable AI Prompt

> Write a natural 20–30 second spoken script from the selected hook. Use one useful middle point and one logical call to action. Make the character sound like a real person rather than a polished brochure. Vary sentence length. Close the loop opened by the hook. Do not add more tips, features, or claims. Then list any removed ideas as possible future videos.

Read the script aloud. Remove repetition, setup the viewer already understands, and any sentence that needs a separate explanation.

## Create The Performance Map

Mark only what materially changes delivery:

- opening emotion;
- where to speed up or slow down;
- one or two words to punch;
- useful pause or reaction;
- ending energy and expression.

### Reusable AI Prompt

> Add a short performance map to this script. Mark meaningful changes in pace, emphasis, pause, emotion, expression, and energy. Keep the character's established personality. Do not direct every word. Suggest one alternate performance for the most important line.

## Build Scenes And Shots

A **scene** is one meaningful story unit. It usually keeps the same purpose, place, time, or action. A **shot** is one camera view or visual piece inside a scene.

Example: “The character tastes several terrible drinks” may be one scene containing a wide shot, drink close-up, sip, reaction, spilled coffee cutaway, and return to the character.

For each scene, record:

- scene purpose;
- narration range;
- approximate time;
- location or context; and
- what changes before the next scene.

For each shot, record:

- what the viewer sees;
- why the shot exists;
- expected screen time;
- source route;
- required asset or reference; and
- how its audio will be handled.

### Reusable AI Prompt

> Break this timed script into the fewest useful scenes, then create the shots inside each scene. Give every scene a story purpose and every shot an attention, clarity, proof, emotion, rhythm, or personality job. Use the presenter as an anchor where useful. Include cutaways that can cover weak generated frames. Choose a source type for every shot, but do not call a provider or spend credits.

## Final Creative Test

Run four quick reads:

- **Sound off:** Does the opening visual still create interest?
- **Eyes closed:** Does the spoken message still make sense and sound human?
- **Normal playback:** Does something purposeful change before attention goes flat?
- **One-sentence recall:** Can a viewer state the main point after one watch?

Fix the script or plan before paid production when any test fails.
