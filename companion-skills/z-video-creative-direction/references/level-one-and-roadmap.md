# Level One Guidance And Future Levels

## Level One: Fast Attention Reel — Built Now

Level One is for a roughly 15–30 second reel with one job:

- one hard hook;
- one useful trust or authority point;
- one call to action;
- one presenter or character direction;
- a few purposeful visual changes; and
- a compact production handoff.

Keep the planning lighter than the production. If the creative packet takes longer to understand than the video, simplify it.

### Hook Test

- Does the right person know this is for them in the first seconds?
- Does it name or show a real problem, desire, mistake, contrast, or consequence?
- Is it sharper than a broad question such as “Want better marketing?”
- Does the rest of the script pay off what the hook opens?

### Compression Test

Remove a line when it repeats the hook, adds a second lesson, lists another feature without advancing the point, sounds like a brochure, needs a separate explanation, or forces a rushed flat delivery. Move useful removed ideas into a future-video list.

### Performance And Visual Test

The script should support real changes in pace, emphasis, emotion, expression, and pauses. Use the presenter as the anchor when appropriate. Refresh attention with a crop, angle, expression, prop, relevant B-roll, screenshot, graphic, cutaway, or text change. Every visual change needs one reason; it does not need to satisfy every possible purpose.

## Level Two: Developed Short Video — Future, Not Built

Intended future scope: roughly 40 seconds to five minutes. It may add a fuller story arc, proof structure, scene plan, character and style references, anchor images, planned variants, more detailed sound direction, and additional approval gates.

This package does not implement Level Two. Use the existing production brief and current human-approved process rather than pretending this skill contains it.

## Level Three: Campaign Or High-Stakes Production — Future, Not Built

Intended future scope: longer, expensive, client-critical, recurring-series, or campaign work. It may add research, audience evidence, concept comparison, full treatment, rights records, continuity plans, asset matrices, shot strategy, testing variants, and formal approval checkpoints.

This package does not implement Level Three. Escalate to a managed production plan and the appropriate approval owner.
